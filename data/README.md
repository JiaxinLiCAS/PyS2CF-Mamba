# Dataset files

Place the downloaded WHU-Hi-LongKou, QUH-Qingyun, and QUH-Tangdaowan MATLAB
files in this directory. Dataset files are not included in this repository.

Please obtain the data from the official sources, follow their terms of use,
and cite the original WHU-Hi and QUH dataset papers.

The code expects the exact directory and file names shown in the main README.
No generated train/validation/test split is stored here.
